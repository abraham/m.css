Text

Body text sits at the base size and line height, inside a comfortable measure. Inline elements cover emphasis, edits, abbreviations, and numbers.

Accessibility

Paragraphs wrap to avoid a lone last word. ins and del keep their underline and strikethrough, so they don't rely on color.

Customize

--m-font-sans, --m-font-size, and --m-measure shape body text.

Headings

The top three levels scale with the window. Long headings wrap in balanced lines.

Accessibility

Use levels in order. Pick a heading for its level in the outline, not for its size.

Customize

--m-density sets the space above and below headings.

Heading groups

In an hgroup, a paragraph before the heading is an eyebrow, and a paragraph after it is a subtitle.

Accessibility

An hgroup holds exactly one heading, so the eyebrow and subtitle stay paragraphs.

Customize

The eyebrow and subtitle use the muted text color.

Lists

Bulleted, numbered, and description lists, plus menu for a row of commands.

Accessibility

Numbered lists use tabular numbers, so the items line up.

Customize

--m-density sets the space between items.

Quotes

A blockquote gets an accent border. A footer inside it is an attribution, and inline q adds quotation marks.

Accessibility

The em dash before a quote's footer is drawn with CSS and isn't read aloud.

Customize

The border uses --m-primary.

Code

Inline code, keyboard keys, sample output, variables, and preformatted blocks that scroll sideways.

Accessibility

Give a pre that can scroll a tabindex="0", so keyboard users can scroll it.

Customize

--m-font-mono sets the code font.
