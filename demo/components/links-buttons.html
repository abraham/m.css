Links

Links use the primary color with a soft underline that thickens on hover.

Accessibility

Links keep their underline, so they don't rely on color. With more contrast, the underline turns solid and the focus ring grows.

Customize

Links use --m-primary.

Buttons

Buttons are solid primary. type="reset" and formnovalidate buttons are secondary outlines.

Accessibility

aria-busy="true" shows a spinner that pulses instead of spinning when motion is reduced. Disabled buttons can't be focused, so explain why an action is unavailable somewhere else.

Customize

The text on a primary button picks black or white for contrast, or --m-on-primary if you set it.

Link buttons

A link with role="button" looks like a button.

Accessibility

aria-disabled="true" dims the link, but it still navigates: stop that with script, or remove the href.

Customize

Same as buttons.

Groups and toggles

role="group" joins its children into one control. Buttons with aria-pressed are toggles, so a group of them is a segmented control.

Accessibility

Label the group with aria-label. Screen readers announce each toggle as pressed or not. This demo moves the pressed state with a small script.

Customize

The pressed state uses a tint of --m-primary and a thicker border.
