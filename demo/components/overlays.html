Dialog

A modal dialog sits on the overlay surface over a blurred backdrop, and the page behind it doesn't scroll.

Accessibility

Open it with showModal(), which this demo does from the button, so focus moves into it and Escape closes it. Label it with aria-labelledby.

Customize

It scales in, unless motion is reduced.

Popover

A popover opened by a popovertarget button, with no JavaScript.

Accessibility

Escape and a click outside close it, and the button tells screen readers whether it's open.

Customize

It slides up into place, unless motion is reduced.

Menus

A popover that is a list, or holds one, is a menu that opens below its button.

Accessibility

This is a disclosure of links and buttons, not an ARIA menu, so Tab moves through the items and no extra keyboard script is needed.

Customize

Where anchor positioning isn't supported, the menu opens centered like other popovers.
