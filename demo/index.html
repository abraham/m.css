Classless CSS

m.css

Link one stylesheet, write semantic HTML, and every element looks clean and modern. No classes.

Same HTML, with and without m.css

This fragment is plain markup: a heading, a paragraph, a form, and a table, with no classes or attributes for styling. Turn m.css off to see what the browser does on its own.

Quick start

  1. Link the stylesheet in your page's head:

    <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@abraham/m.css/dist/m.min.css" />

  2. Write semantic HTML. Landmarks, headings, forms, and tables are styled as they are:

    <main>
  <h1>Hello</h1>
  <p>Plain HTML, styled.</p>
  <button>Get started</button>
</main>

  3. Optionally, set a property or two to make it yours:

    :root {
  --m-primary: #2563eb;
  --m-density: 1.1;
}

Or install it with npm install @abraham/m.css and import it through your bundler. Try the properties live on the Theming page, or with the Settings button at the top of any page.

Principles

  • Strictly classless. m.css only styles elements, attributes, and ARIA states. See any component page.
  • Easy to override. Every rule sits in a cascade layer with zero specificity, so your CSS wins without !important.
  • Light and dark. It follows the system, and data-theme overrides it for the page or any section. See Theming.
  • Motion and contrast preferences. Reduced motion and more contrast are honored, with attribute overrides. See Theming.
  • Accessible by default. Text meets WCAG AA, focus is always visible, and forced-colors mode redraws custom controls in system colors.
