Theming

A handful of custom properties restyle everything, and attributes switch schemes and preferences.

Properties

Set these on :root for the whole page, or on any element to scope them to that part of the page. Spacing, type, and every color variant derive from them.

Property Default Controls
--m-primary oklch(55% 0.19 40) Links, buttons, focus rings, checked controls, and every hover and tint variant
--m-on-primary Black or white, for contrast Text on primary backgrounds
--m-density 1 All spacing and line height
--m-radius 0.5rem Corner rounding
--m-font-size 1rem Body text size
--m-measure 100ch The width of the main column
--m-font-sans system-ui, sans-serif Body and heading font
--m-font-mono ui-monospace, …, monospace Code font

Light and dark

The page follows the system preference. data-theme="light" or "dark" forces a scheme for the whole page or for any section, like these two cards.

Motion and contrast

m.css follows prefers-reduced-motion and prefers-contrast: more. To force them on for a page or a section, set data-motion="reduce" or data-contrast="more".

To test the system settings, emulate them in your browser's developer tools. In Chromium, open the Rendering panel and set "Emulate CSS media feature" for prefers-reduced-motion, prefers-contrast, or forced-colors.

See it applied

The showcase has whole pages themed with only these properties and attributes, such as a long-read magazine essay. Each one shows its complete theme at the bottom.
